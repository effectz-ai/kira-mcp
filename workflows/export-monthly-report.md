# Workflow: Create the monthly report and export it as PDF

## Goal
A new Word document "Monthly Report.docx" with the text below is saved on the
Desktop, and a PDF copy "Monthly Report.pdf" is saved next to it.

## Preconditions
- Microsoft Word is installed and signed in.
- No file named "Monthly Report.docx" or "Monthly Report.pdf" is on the Desktop.
- Nothing else important is open in Word.

## Steps
1. Press the **Windows** key, type `Word` and press **Enter** to open Microsoft Word.
2. On the Word start screen, click **Blank document**.
3. Type this text exactly, pressing **Enter** where the lines break:

   Monthly Report - October 2026
   Prepared by: Kira automation test
   Summary: This document was created and exported automatically.

4. Save the document: press **Ctrl+S**. If a small "Save this file" box
   appears, click **More options...** to get the full save dialog.
5. In the save dialog, click **Desktop** in the left sidebar, set the file
   name to `Monthly Report` and click **Save**.
6. Open the **File** menu, choose **Export**, then **Create PDF/XPS Document**
   and click **Create PDF/XPS**.
7. In the publish dialog, check that **Desktop** is selected and the file
   name is `Monthly Report`, then click **Publish**.
8. If the PDF opens in another app, close only that PDF viewer window.

## Expected result
- "Monthly Report.docx" and "Monthly Report.pdf" are both on the Desktop.
- The PDF shows the three lines of text.
- Word is still open showing "Monthly Report.docx".

## Do NOT
- Do not overwrite an existing file. If Word says a file already exists,
  stop and ask.
- Do not close Word.
- Do not type anything other than the text in step 3.
- Do not save to OneDrive "Documents" or any folder other than Desktop.

## Critical actions
Extra words that must always ask first for this task only.
- export
- create pdf
